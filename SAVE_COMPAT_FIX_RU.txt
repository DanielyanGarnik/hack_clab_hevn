Последняя минута — v0.6.6 Save Compatibility Hotfix

Исправлено падение на строке 108 в scripts/state.gd:
  Invalid access to property or key 'choice_effects' on a base object of type 'Dictionary'.

Причина: при загрузке старого сохранения новые поля истории отсутствовали.
Теперь все необязательные поля берутся через Dictionary.get() с безопасным значением
по умолчанию и проверяются на корректный тип. Обновлённая игра использует старое
сохранение user://last_minute_v06.json без его удаления.

Запуск: в Godot 4.7.2 импортируйте project.godot из распакованной папки и нажмите F5.
В архиве есть полный проект (прошлые уровни, персонажи, диалоги, ловушки и ресурсы).
Примечание: проверен статически; непосредственный запуск в Godot не подтверждён.
