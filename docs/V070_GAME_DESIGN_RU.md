# Что изменилось в v0.7.0

| Претензия к прошлой версии | Решение |
| --- | --- |
| 7 несвязанных взаимодействий в главе | Теперь три сюжетные сцены; предмет, сообщения, фразы, выборы идут цепочкой после одного E |
| Выбор не ощущается | Подписаны эффекты «Доверие/Улика»; реакция следующей сцены зависит от ответа; доверие/улики участвуют в подсказках, ловушках и финалах |
| R/Q необязательны | Приближение создаёт физический «разлом»; без реальной перемотки до точки его появления не пройти. Во временных главах past-группы требуют Q; разрушенный мост восстанавливается в прошлом |
| Текст мешает игре | Компактный HUD, модальные окна, ограничение строк, отдельные области кнопок и текста |
| Диалоги односторонние | Герой — слева, собеседник — справа; активный говорящий выделяется |
| Слишком много текста | Разрозненные события объединены; у второстепенных событий не более одной реплики, в ключевых до двух. Один визуальный документ на сцену |

## Особенности прохождения
- Первое переключение Q доступно только в главах с `shift=true` (остальные главы обучают R).
- Любая обязательная сцена прошлого остаётся заблокированной до смены временного слоя.
- Чтобы решить временную преграду R, **нужно переместить персонажа обратно в мире**; обычное нажатие R без достаточно длинной истории передвижения не сработает.
- Кодовые панели не отменены, но собранные улики делают подсказку конкретнее.
- Прогресс старой версии с 7 событий отображается в новые 3 сцены. Старые решения не удаляются.

## Описание тестов
`validate_project.py` проверяет 13 глав, 40 связанных сцен, 41 уникальный выбор, 844 локализованных текстовых элемента, пути к изображениям, места расположения критичных элементов UI и наличие условий для R/Q. Это **не** Godot runtime-тест.
