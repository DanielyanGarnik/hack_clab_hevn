# Последняя минута v0.7.2 — текст и кнопка диалога

- Исходный проект v0.7.1 сохранён, все 13 глав / 3 героя / выборы / ловушки / язык RU-HY-EN на месте.
- Каждая надпись внутри невидимой области отсечения SafeText. Шрифт подбирается по фактическому размеру текста (Font.get_multiline_string_size), с разумным минимумом. Длинная строка физически не может рисоваться поверх соседней карточки.
- Карточки выбора персонажа переделаны с лаконичными локализованными описаниями, один стиль на всех языках. Длинные оригинальные описания сохранены в story.json, но не загромождают меню.
- Кнопка продолжения диалога содержит только стрелку; слова «Следующий / Next / Հաջորդը» отсутствуют на самой кнопке. Наведение по-прежнему показывает подсказку.
- Светлая слоновая кость / приглушенный беж используются одинаково для RU / EN / HY, без языковых изменений в палитре.
- Игровое поведение, повторы R / Q и сброс прогресса при новом запуске не менялись.
- Проверка Godot должна включать переключение языка и тест карточек, диалогов, выбора ответа, просмотра бумаг, меню и финала.
